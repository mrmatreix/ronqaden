# متجر رونق اليمن | Rawnaq Yemen Luxury E-Commerce Store 🇾🇪💎

متجر إلكتروني متكامل وعصري للجمهورية اليمنية، مع لوحة تحكم إدارة تفاعلية ذكية (Admin Dashboard).

---

## 🌟 المميزات الرئيسية:
- **واجهة تسوق عصرية وذكية**: تصميم زجاجي فاخر (Glassmorphism)، دعم كامل للوضع الليلي (Dark Mode) والنهاري، وتجربة مستخدم سلسة وفائقة السرعة.
- **توطين متكامل لليمن**:
  - العملة: الريال اليمني (`ر.ي`).
  - دعم جميع المحافظات والمدن اليمنية (صنعاء، عدن، حضرموت، تعز، إب، الحديدة، مأرب، وغيرها).
  - دعم أرقام الهواتف اليمنية (يمن موبايل، يو، سبأفون، واي).
  - وسائل دفع متعددة ومحلية: كاش عند الاستلام، **حوالة عبر الشبكة الموحدة فقط (UNS)**، بنك الكريمي (حاسب / إم فلوس)، والمحافظ الإلكترونية (ون كاش / فلوسك / جوالي).
- **لوحة تحكم إدارة شاملة (`admin.html`)**:
  - إضافة منتجات جديدة مع رفع الصور وتحديد المواصفات والألوان والأسعار.
  - تعديل وحذف المنتجات وتحديث المخزون.
  - متابعة وإدارة طلبات العملاء وتغيير حالات الطلبات (قيد الانتظار، جاري التجهيز، مكتمل، ملغي).
  - إنشاء وإدارة كوبونات وأكواد الخصم.
  - مزامنة لحظية بين لوحة الإدارة والمتجر عبر `LocalStorage`.

---

## 🚀 كيفية التشغيل والاستخدام:
1. قم بفتح ملف `index.html` في أي متصفح ويب لتصفح المتجر وإجراء الطلبات.
2. قم بفتح ملف `admin.html` للوصول إلى لوحة تحكم الإدارة.

---

## 📁 هيكل المشروع:
```text
├── index.html       # صفحة المتجر الرئيسية للعملاء
├── admin.html       # لوحة تحكم الإدارة
├── css/
│   ├── style.css    # تصميم وهوية متجر رونق
│   └── admin.css    # تصميم لوحة تحكم الإدارة
├── js/
│   ├── data.js      # قاعدة البيانات الافتراضية ومحرك المزامنة
│   ├── app.js       # منطق وتفاعلات صفحة المتجر والسلة والدفع
│   └── admin.js     # منطق لوحة الإدارة والـ CRUD
└── README.md        # توثيق المشروع
```
